# School Management System

A comprehensive school management platform built with Django to automate academic and administrative operations.

## Features

- Student Admission Management
- Fee Collection & Dues Tracking
- Session Management
- Teacher & Staff Management
- Expenses & Assets Tracking
- Analytics Dashboard with Charts
- Admin, Teacher, and Student Panels

## Technologies Used

- Python
- Django
- SQLite / PostgreSQL
- Bootstrap
- Plotly

## Purpose

Designed to simplify school administration and improve decision-making through data-driven insights.

## Installation

1. Clone the repository
2. Install dependencies
3. Run migrations
4. Start the development server
